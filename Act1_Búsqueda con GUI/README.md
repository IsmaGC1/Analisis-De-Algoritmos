# Práctica 1 - Búsqueda con GUI

Este proyecto implementa una interfaz gráfica (GUI) en Tkinter para comparar los tiempos de ejecución de dos algoritmos de búsqueda: búsqueda lineal y búsqueda binaria.  
Además, se generan gráficas dinámicas utilizando Matplotlib para visualizar los resultados.

---

## Características
- Generación automática de listas con diferentes tamaños.
- Búsqueda lineal y binaria sobre listas ordenadas.
- Medición del tiempo promedio de cada algoritmo (5 repeticiones).
- Representación gráfica del tiempo de ejecución.
- Interfaz gráfica amigable construida con Tkinter.
- Soporte para tamaños de lista: 100, 1,000, 10,000 y 100,000.

---

## Requisitos
Asegúrate de tener Python 3.10+ instalado.  
Además, instala las dependencias necesarias con los requeriments.
